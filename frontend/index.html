Information

Resynthzer adalah aplikasi open-source gratis untuk membantu kamu meng-upscale dan mengompres foto maupun video dengan cepat. Semua orang boleh menggunakannya, mempelajari cara kerjanya, dan mengembangkan versinya sendiri.

Pilih media, tentukan mode dan engine, lalu klik Generate Output. Resynthzer menangani proses pemrosesan secara lokal di komputer kamu, sehingga file media tidak perlu diunggah ke layanan online.

Gunakan Real-ESRGAN untuk peningkatan berbasis AI, atau FFmpeg untuk scaling dan kompresi yang ringan. Performa dan waktu proses bergantung pada ukuran media serta kemampuan CPU, GPU, dan VRAM perangkat.

Resynthzer masih dalam tahap pengembangan. Pastikan FFmpeg dan Real-ESRGAN tersedia di folder tools aplikasi sebelum memulai proses.
